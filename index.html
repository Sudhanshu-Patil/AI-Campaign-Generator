Step 6 of 7 · the promotion barrier

Approving is reviewing a changeset

An AI suggestion is written to a proposals table that no downstream agent can read. It becomes a campaign term only when a human with campaign:approve accepts this diff — a single transaction that writes an immutable version and an audit row. There is no other path.

Four-layer validation

1 · Schema
Strict types. Reject, retry once, then fall back to asking a human.
2 · Groundedness
Every fact needs a source URL and a verbatim span. Unsourced facts are dropped, not stored.
3 · Business rules
Bounds-checked against derived limits before anything reaches a screen.
4 · Provenance
Source, model, prompt version, confidence and evidence stamped on every value.

After negotiation

Creator terms are instances, not edits

A negotiated deal never modifies the campaign. It is a Deal that inherits campaign defaults, stores only what differs, and is bounds-checked against the negotiation policy on write. Campaign is to Deal as class is to instance.

System architecture

      
Input collection through brief approval to downstream access. Purple is non-deterministic and always validated; blue is deterministic; green requires a human.

    

    


    
The promotion barrier

    
How a suggestion becomes a term — and the three places it can die before it ever reaches a brand. This is the path that makes “an AI recommendation silently becoming an approved campaign term” structurally impossible rather than merely discouraged.

    


    

      
Tenant isolation

        
Postgres row-level security, tenant_id on every row.

        
Object storage keyed by tenant prefix.

        
No cross-tenant retrieval in any prompt; no shared embedding index.

        
Per-tenant cost and rate budgets.

      

      
Failure handling

        
Every failure degrades to ask the human, never to guess.

        
Durable steps, idempotency keys, per-step timeouts.

        
Per-campaign dollar budget guard with a circuit breaker.

        
Extraction is a pure function of a stored snapshot, so it is replayable.

      

      
Cost & latency

        
Target ≤ $0.35 per campaign setup.

        
Ingestion p95 ≤ 45s, asynchronous and non-blocking.

        
Interaction turn p95 ≤ 2.5s.

        
Small model for extraction and phrasing; frontier model only for strategy prose. Prompt caching across the session is the dominant lever.
